## Python Typing Speed Test (Console Based)

This project is a simple console-based typing speed and accuracy test written in Python. It helps users practice typing by displaying different predefined lines of text and measuring how fast and how accurately the user types them.

The program provides multiple typing exercises such as lowercase letters, uppercase letters, keyboard patterns, and full sentences. After typing, the program calculates the time taken and typing accuracy by comparing the user input with the original line.

##  🚀 Features

Multiple typing practice lines

Measures time taken to type

Calculates typing accuracy (%)

Checks whether the typed line is correct or incorrect

Menu-driven program (choose line from options)

Repeat test option (continue practice)**
